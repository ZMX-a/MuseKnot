# MuseKnot

**把一闪而过的想法记下来，让后来的自己继续写。**

MuseKnot 是一个可自行部署的个人记录与写作 PWA。你可以随手记灵感、写日记、整理角色设定，让一条记录随着时间不断续写；也可以把几条相关记录连成脉络，最后导出成长图保存或分享。

## 它能帮你做什么

有些内容不适合一次写完：今天记下一句话，过几天有了新的理解，过一个月又想补充。

MuseKnot 让这些内容留在同一条记录里，同时保留每次续写的时间和段落。之后想整理主题时，把相关记录连在一起，调整阅读顺序，形成一条脉络。需要留存或分享时，再把已保存的内容导出成长图。

**记下来 → 接着写 → 连成脉络 → 保存成长图。**

它适合这些使用场景：

- **随手记录**：读书时的一句话、散步时的念头、梦醒后还记得的片段。
- **持续写作**：一篇尚未完成的散文、日记、一个不断补充的想法。
- **创作整理**：把 OC（原创角色）的设定、片段和故事线放在一起。
- **回看与分享**：按自己安排的顺序阅读相关记录，或生成图片保存。

## 从一条记录开始

1. 在首页点击 **「＋ 记录」**，写下一段内容，也可以添加图片。名称可以留空，需要时再起名。
2. 从 **「我的笔记」** 进入记录库，找到这条记录，继续写。每次续写独立保存；编辑已有段落时保留修改历史。
3. 在 **「记录脉络」** 中选择相关记录并连接，按想要的阅读顺序排列。
4. 在记录详情或脉络中选择 **「导出长图」**，生成预览后保存。内容过长时会自动分图。

连接脉络不会合并或改写原记录；同名记录也不会自动合并。

## 已有功能

| 功能 | 使用方式 |
|---|---|
| 记录库 | 支持灵感、图片、散文、日记、OC、梦的记录；可选名称、搜索与标签。 |
| 续写与修改历史 | 在原记录下追加独立段落；编辑和恢复版本时保留此前内容。 |
| 记录脉络 | 用记录 ID 连接已有内容，支持调整顺序。 |
| 长图导出 | 单条记录或整条脉络均可导出，包含已保存的续写和配图，可隐藏时间。 |
| 个人背景 | 默认白底；支持上传 PNG、JPG、WebP，最大 8 MB，可恢复默认。 |
| 手机与 PWA | 适配手机，可添加到主屏幕；支持的设备可通过系统面板分享图片。 |
| 私有账号 | 邀请码注册、备用恢复码、30 天登录会话，以及账号间的数据隔离。 |
| 自行部署与备份 | 一个 Node.js 服务提供页面和 API，使用内置 SQLite，提供在线备份脚本。 |

## 本地运行

除在线体验外，你也可以使用仓库源码在自己的电脑或服务器运行应用。GitHub 提供源码和说明；当前完整应用不能仅通过 GitHub Pages 提供。

需要 **Node.js 22.23.2+ 或 24.x** 和 npm。无需单独安装数据库。

```bash
git clone https://github.com/ZMX-a/MuseKnot.git
cd MuseKnot
npm ci
npm run setup
npm run build
npm start
```

打开终端打印的邀请链接创建第一个账号，或访问 <http://127.0.0.1:4173/museknot/>。

- `setup` 在 `.env` 不存在时生成本地配置和随机邀请码，不覆盖已有配置。
- 注册使用邮箱、密码和邀请码；通过邀请链接进入会自动带入邀请码。
- 密码至少 12 个字符，可使用容易记住的长句。日常登录只需邮箱和密码。

### 先用示例内容试试

保持服务运行，在另一个终端进入项目目录并执行：

```bash
npm run demo
```

然后使用 `demo@example.test` / `demo-only-password-2026` 登录。

这是本地开发专用的虚构账号。示例脚本只允许在本机开发环境运行，重复执行不会覆盖已有示例记录。它不会提供其他部署实例的账号或邀请码。

## 在手机上使用

将应用部署到具有有效 HTTPS 的服务器后，用手机浏览器打开自己的地址：

- 安卓：在支持的浏览器菜单中安装应用。
- iPhone / iPad：在 Safari 中选择「添加到主屏幕」。

从桌面图标进入后可以使用同一套记录功能。安装方式、文件保存和分享能力因系统与浏览器而异，首次从独立窗口进入时可能需要重新登录。

**目前需要联网读取和提交记录。** Service Worker 仅提供通用断网页面，不缓存笔记、账号接口或图片；完整离线编辑与同步尚未实现。

服务器配置、数据目录、备份和更新方式见 [自行部署](docs/SELF_HOSTING.md)。

## 技术与验证

- **前端**：React 18 + htm，esbuild 构建；仓库中保留 D3 / Three.js 的连接与空间视图代码。
- **服务端**：Node.js HTTP 服务与内置 `node:sqlite`，同源提供页面和 API。
- **内容结构**：记录包含独立段落及修改历史；脉络保存有序的记录 ID。
- **账号**：密码使用 scrypt；登录 Cookie 使用 HttpOnly / SameSite，生产环境启用 Secure。

```bash
npm run build
npm test
```

测试覆盖记录迁移、独立续写、历史版本、账号隔离、草稿导入、脉络排序、长图排版、PWA、自定义名称与背景设置。GitHub Actions 在 Node 22 和 24 下运行构建与检查，实际结果见 [Actions](https://github.com/ZMX-a/MuseKnot/actions)。

更多实现细节见 [实现与取舍](docs/ARCHITECTURE.md)。
