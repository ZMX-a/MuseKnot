# MuseKnot

**记下片刻，续成故事，连成脉络。**

A self-hosted note-taking PWA for small ideas, independent continuations, connected threads, and long-image export.

[English](README_EN.md) · [部署说明](docs/SELF_HOSTING.md) · [实现与取舍](docs/ARCHITECTURE.md) · [贡献指南](CONTRIBUTING.md)

![记录库：自定义名称与正文摘要](docs/screenshots/library.png)

MuseKnot 从一个实际写作习惯出发：第一次记下的内容，不应该被后来的想法覆盖。你可以接着写，让每次续写保留自己的时间；也可以编辑其中一段，并保留修改前的版本。需要整理时，把不同记录连接成脉络，自行安排阅读顺序。

## 已有功能

- **记录库**：灵感、图片、散文、日记、OC、梦的记录；可选的自定义名称，支持后续改名、搜索与标签。
- **独立续写与历史**：每次续写单独保存；编辑、恢复历史版本时保留此前内容。
- **记录脉络**：连接一条或多条记录，调整顺序；关联使用记录 ID，不按同名内容自动合并。
- **长图导出**：导出单条记录或整条脉络，包含已保存的续写与配图；可隐藏时间，内容过长时自动分图。
- **PWA**：桌面图标、独立窗口、手机布局与断网提示；支持的设备可通过系统面板分享图片。
- **自定义首页背景**：账号 → 首页背景，支持 PNG、JPG、WebP（最大 8 MB），登录后跨设备使用；可恢复默认，其他账号无法读取你上传的图片。
- **私有账号**：邀请码注册、30 天登录会话、备用恢复码、账号间的数据隔离。
- **自行部署**：Node.js 内置 SQLite，支持在线备份，前端构建后由同一个服务提供。

## 本地运行

需要 **Node.js 22.23.2+ 或 24.x** 和 npm。无需单独安装数据库服务。

```bash
npm ci
npm run setup
npm run build
npm start
```

`setup` 只在 `.env` 不存在时创建本地配置，并生成随机邀请码。首次运行时，使用终端打印的邀请链接创建账号；如果已有 `.env`，请使用其中的本地邀请码。入口是 <http://127.0.0.1:4173/museknot/>。密码至少 12 个字符。

想先看看虚构数据？保持服务运行，在另一个终端执行：

```bash
npm run demo
```

然后用 `demo@example.test` / `demo-only-password-2026` 登录。这是**本地开发专用**的虚构账号；示例脚本拒绝向非本机或非开发环境写入。重复运行不会覆盖已有示例记录。

## 验证

```bash
npm run build
npm test
```

当前自动检查覆盖独立段落、修改历史、旧记录迁移、账号隔离、草稿导入、长图排版、脉络排序、PWA 安装清单、自定义名称及背景账号隔离。GitHub Actions 配置在 Node 22 和 24 下执行构建与检查；发布后的实际运行结果以 Actions 页面为准。

## 手机使用

生产部署需要有效 HTTPS。安卓可通过浏览器菜单安装应用；苹果可在 Safari 中选择“添加到主屏幕”。不同浏览器的安装方式与文件分享能力会有差异，首次从桌面图标打开时可能需要重新登录。

这一版**需要联网读取和提交记录**。Service Worker 仅提供通用断网页面，不缓存账号接口、笔记、图片或应用包，也不会为了更新强制刷新正在输入的页面。完整离线编辑与同步仍在后续计划中。

## 技术与数据

- React 18 + htm；esbuild 构建；D3 / Three.js 支持既有连接与空间视图代码。
- Node.js HTTP 服务、`node:sqlite`；同源部署，避免额外维护独立 API 域名。
- 内容按“记录 → 段落 → 修改历史”组织；脉络只保存有序的记录 ID。
- 账号密码使用 scrypt，登录 Cookie 使用 HttpOnly / SameSite，生产环境启用 Secure。
- 笔记和图片以明文存储在服务器数据库中，**不是端到端加密**。数据库和备份应由部署者妥善保护。

详见 [实现与取舍](docs/ARCHITECTURE.md) 和 [安全说明](SECURITY.md)。
